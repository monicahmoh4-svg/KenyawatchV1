How It Works

From raw contracts to citizen power

A transparent, four-step pipeline turns public procurement data into actionable intelligence.

1. Ingest

Pull machine-readable records from the Open Contracting Data Standard (OCDS) feed, plus documented public-interest cases.

2. Score

A transparent rules engine scores every contract for risk — bid type, value, supplier timing, and vague scope.

3. Verify

Cross-check claimed project completion against live satellite imagery to expose "ghost" projects.

4. Act

Citizens report anonymously, AI triages credibility, and cases route to EACC, PPRA, or the DPP.

Click "Refresh Status" to load recent sync history.

Note: Kenya's official procurement portal (PPIP) is not yet fully OCDS-compliant, so live sync results depend on what the upstream registry currently publishes for the selected year — it may return zero new records for some years. This does not affect the documented and reference records already in the database.

Data & Methodology

Every contract in this platform carries a data type so you always know what you're looking at:

Documented

Real, publicly reported cases sourced from Auditor-General reports, court/EACC proceedings, and mainstream investigative reporting. Each record links to its source.

Live Sync

Pulled directly from the Open Contracting Partnership's machine-readable Kenya feed via the "Sync Data" tab, using the official Open Contracting Data Standard (OCDS).

Reference

Representative sample records ensuring every one of the 47 counties has baseline data to browse while official machine-readable coverage is incomplete. Never presented as verified fact.

Risk scores are computed by a transparent, rules-based engine (bid type, contract value, timing between supplier registration and award, and vague-scope language) — the same rules apply whether a contract was seeded, synced, or manually scanned.

Kenya's Public Procurement Information Portal (PPIP) is still working toward full OCDS compliance, per Kenya's Open Government Partnership commitments — so no single automated feed currently covers every contract, in every county, for every year. This platform combines what's verifiably documented with what's live-syncable, and is transparent about the gap.
