Data & Methodology

Every contract carries a data type so you always know what you're looking at:

DOCUMENTED

Real, publicly reported cases from Auditor-General reports, EACC/DPP proceedings, and investigative journalism.

LIVE SYNC

Pulled from the Open Contracting Partnership's machine-readable Kenya feed via the Sync Data tab.

REFERENCE

Representative samples ensuring all 47 counties have baseline data while official coverage is incomplete.

Risk scores use a transparent rules-based engine (bid type, value, supplier timing, vague scope) applied uniformly to all contracts.
